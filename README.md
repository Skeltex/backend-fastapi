# backend-fastapi

REST API блога на FastAPI: пользователи, категории, местоположения, публикации и комментарии. Проект перенесен с Django, данные хранятся в SQLite.

## Локальный запуск

Нужны Python 3.14 и [uv](https://docs.astral.sh/uv/).

1. Скопируйте `.env.example` в `.env` и задайте `SECRET_KEY` длиной от 32 символов. Сгенерировать ключ можно так:

   ```bash
   python -c "import secrets; print(secrets.token_urlsafe(48))"
   ```

2. Установите зависимости и примените миграции:

   ```bash
   uv sync
   uv run alembic upgrade head
   ```

3. Запустите сервер:

   ```bash
   uv run fastapi dev main.py
   ```

API доступно по адресу http://localhost:8000/api/v1, документация по адресу http://localhost:8000/docs.

## Docker

```bash
docker compose up --build
```

Миграции применяются при старте контейнера. База лежит в `data/`, логи в `logs/`. Приложение в контейнере работает от пользователя с UID 1000, поэтому на Linux эти каталоги нужно создать заранее от своего пользователя.

## Настройки

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `SECRET_KEY` | нет, обязательна | Ключ подписи JWT |
| `ALGORITHM` | `HS256` | Алгоритм подписи: `HS256`, `HS384` или `HS512` |
| `ACCESS_TOKEN_EXPIRE_MINUTES` | `30` | Время жизни токена в минутах |
| `DATABASE_URL` | `data/db.sqlite3` в корне проекта | Строка подключения SQLAlchemy |
| `LOG_FILE` | `logs/app.log` в корне проекта | Файл логов |
| `CORS_ORIGINS` | `["*"]` | Разрешенные источники для CORS |

## Доступ

- Регистрация (`POST /api/v1/users/`) и чтение опубликованных данных доступны без токена.
- Токен выдает `POST /api/v1/auth/token`, свой профиль доступен по `/api/v1/users/me`.
- Публикации и комментарии изменяет и удаляет автор или администратор.
- Категории, местоположения и чужие учетные записи изменяет только администратор. Первого администратора назначают в базе: `UPDATE auth_user SET is_superuser = 1 WHERE username = '...';`
- Неопубликованные записи, отложенные публикации и публикации из скрытых категорий видят только их автор и администратор.
- Пользователи, перенесенные из Django, входят со старым паролем. При первом входе хэш пароля переводится на bcrypt.
